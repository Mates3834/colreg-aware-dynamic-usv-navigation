# Scope and Limitations

The encounter classifier and avoidance logic are deliberately simplified.

This repository does not implement:
- a formal/legal COLREG expert system,
- AIS decoding,
- radar tracking,
- electronic nautical charts,
- vessel-domain models,
- certified collision-avoidance logic,
- weather routing,
- 3-DoF/6-DoF hydrodynamics,
- MPC/NMPC tracking,
- real bridge or vessel integration.

The project is intended as a research-oriented autonomous-navigation simulation.
